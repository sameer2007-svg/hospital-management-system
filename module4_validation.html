Client-Side JavaScript Validation Architecture & Implementation
Subject: Web Technology / Full Stack Development Application: MediCare Hospital Management System Script Language: JavaScript (ES6+) Date: 14-Oct-2026

1. Aim and Objectives

The primary objective of client-side validation in the Hospital Registration System is to ensure data integrity, enhance user experience (UX), and prevent invalid inputs before form submission. It prevents corrupt records (such as letters in contact numbers or digits in patient names) by intercepting keyboard events in real-time and evaluating regular expression (RegEx) constraints.

2. Validation Rules & Constraints Matrix

3. JavaScript Scripting Implementation

The validation mechanism uses a two-tier defense approach: Tier 1: Keystroke Interception (onKeypress / onInput) prevents illegal characters from appearing in the input box altogether. Tier 2: Pattern Evaluation (onBlur / onSubmit) tests the complete field value and displays a red border, shake animation, and helpful error text if requirements are unmet.

Listing 3.1: Keystroke Filter for Name & Phone Fields
// 1. Restrict phone inputs: Block alphabetic characters on keydown/keypress function enforceNumericOnly(event) { const allowedKeys = ['Backspace', 'Tab', 'ArrowLeft', 'ArrowRight', 'Delete']; if (allowedKeys.includes(event.key)) return; // Allow only digits, plus sign and hyphen if (!/[\d+\-\s]/.test(event.key)) { event.preventDefault(); // Reject the character! showInputShake(event.target, "Numbers only! Alphabets are blocked."); } } // 2. Restrict name inputs: Block digits function enforceAlphaOnly(event) { if (/[\d]/.test(event.key)) { event.preventDefault(); // Block numbers showInputShake(event.target, "Letters only! Numbers are not allowed in names."); } }
Listing 3.2: Complete Field Validator with Dynamic Error Message
function validateField(input) { const val = input.value.trim(); const fieldType = input.dataset.validate; if (input.hasAttribute('required') && !val) { return setFieldError(input, "This field is required"); } if (fieldType === 'phone' && !/^[\d+\-\s]{10,15}$/.test(val)) { return setFieldError(input, "Enter a valid 10-digit phone number"); } if (fieldType === 'pincode' && !/^\d{6}$/.test(val)) { return setFieldError(input, "Pincode must be exactly 6 digits"); } if (fieldType === 'email' && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(val)) { return setFieldError(input, "Enter a valid email address (e.g. name@domain.com)"); } clearFieldError(input); return true; }
